---
title: Model sources
description: Choose SuperPlane models, your API key, or ChatGPT subscriptions for workspace agents.
---

A workspace runs its agents on one model source. Open **Settings → Models** and click **Change model source**. The dialog lists the sources your organization can use.

The source applies to every automation in the workspace. Switching it replaces the agent those automations use.

## Compare the sources

| Source | Use it when | Model charges |
| --- | --- | --- |
| **SuperPlane** | You want SuperPlane to run the agents. | SuperPlane bills tokens at the provider rate plus 10%. |
| **Your API key** | You have a Claude, OpenAI, or OpenRouter API key. | Your provider bills the tokens, without the SuperPlane 10% platform fee. |
| **ChatGPT subscriptions** | Each task owner has a ChatGPT subscription. | The owner's ChatGPT plan covers Codex model use. |

SuperPlane bills machine time for every source. Read [Costs and budgets](/billing/costs-budgets) for rates and the monthly allowance.

## Set up a source

- [Bring your own key](/billing/bring-your-own-key) connects a Claude, OpenAI, or OpenRouter API key.
- [Bring your own subscription](/billing/bring-your-own-subscription) connects personal ChatGPT subscriptions for Codex.

After the source is active, choose models on the same page. Keep **Use all available models** selected, or clear it and select the models agents can use. Click **Save models**.

You can view **Models** when you can read the workspace. You can change the source and the model list when you can update the workspace.
