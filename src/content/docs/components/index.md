Components are the triggers and actions that form SuperPlane workflows. Choose a category, then open a provider page for its configuration, events, actions and output.

## Core workflow components

- [Core](/components/core) — triggers, approvals, control flow, HTTP, GraphQL, SSH, memory and Factory actions.
- [Daytona](/components/daytona) — isolated code execution environments.
