## See a software factory run in the background

**In this video, you will see:**

- How a task moves from **Backlog** to **Done**.
- The task moving to **Implement** while an agent works on the change.
- A pull request waiting for review in **Verify**.
- Completed work reaching **Done**.

Starting a task authorizes code work for that task. Review the title, description, repository and factory line before you confirm. Manual **Start** is the default. Automatic CI repair requires configuration, and passing checks alone does not move a task to Done. The default closure automation records completion after merge or rejection after closure without merge.
